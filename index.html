The course rhythm

Understand. Experiment. Explain.

01 / Concept

Keep the mathematics visible

Definitions and assumptions come before code. Learn what a formula says, when it applies, and how it can fail.

02 / Experiment

Predict before pressing run

Move a parameter, compare paths, and distinguish model behavior from Monte Carlo variability.

03 / Evidence

Return to the observations

Estimate, validate in time order, compare decisions, and communicate uncertainty in a reproducible notebook.

READY TO STUDY · MODULE 14

Can you explain what your evidence supports?

Present the same project in six minutes, connect each claim to an executed result, and rehearse an individual explanation of a formula, figure, and short code trace. The bike-sharing example distinguishes observations, exact model calculations, simulation, and assumptions.
